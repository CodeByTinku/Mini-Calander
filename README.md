# Mini-Calander
A compact, accessible month-view calendar component for web projects.
___
## Features
- Lightweight month grid with date selection.
- Prev/Next month, Today jump, customizable week start.
- Disable dates, min/max range, event markers.
- Keyboard navigation and ARIA-friendly markup.
